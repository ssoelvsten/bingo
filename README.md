# An (unfair) Bingo Generator

For parties, you might want to do a bingo with custom words and/or size.
Usually, there would be two prices up for grabs: the first one to fill out an
entire row and the one to fill out the entire card. Yet, it can happen that the
same person gets both prices which kind of sours the mood.

So, these scripts generate bingo cards based on a pre-defined history of words
to be drawn. Using this, we can ensure (1) that no one gains two prices and and
(2) only one person wins a price every time.

## Usage

- `gen.py`: Generates random cards of the desired size and with the above
  guarantees.
- `html.py`: Converts the cards generated by `gen.py` into html documents.

Inputs are parsed and the scripts orchestrated in `main.py`. For arguments,
please consult its `--help`.

```bash
python3 ./main.py --help
```
